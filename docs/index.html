gap is distance from the pair's own recent norm · z is that in its own standard deviations · cost is half the bid-offer on each leg · expected is what a signal this size has historically recovered within ten days. Most candidates do not clear their own costs as a standalone round trip — the honest use is choosing between trades you were doing anyway.

A bond's raw distance from the curve is not a signal: some bonds sit permanently cheap. Each is scored against its own trailing 60-day window, which excludes the day being scored. Measured over this sample the residuals mean-revert with a half-life near 11 days; run python -m signals.validate for the current numbers. One 9-month sample in one regime — evidence the mechanism works, not a forecast of what it pays.
